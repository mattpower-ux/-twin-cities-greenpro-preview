# Twin Cities GreenPro Finder preview

This repository contains the generated, static preview of the Twin Cities directory. It has no server, admin interface, submissions, or local working data. The Project Journal images are included as WebP files.

To view the preview through GitHub Pages, publish the `main` branch from the repository root. The site uses a noindex directive and hash routes so internal pages work on a project Pages URL.

The editable project source is maintained separately in `C:\Users\mattp\Desktop\GreenPro`.
